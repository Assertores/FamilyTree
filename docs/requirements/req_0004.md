# Supported Format Version
## Context
<!-- The situation that makes this requirement necessary, e.g. a user need, a law or standard, or a constraint from another system. -->
The format of the data files may have to change in the future, after data has been collected. Data written before the Format Version existed is not supported.

## Requirement Statement
<!-- A bland statement of the requirement using the [RFC 2119](https://datatracker.ietf.org/doc/html/rfc2119) standardized vocabulary. The ruling SHALL be stated in an assertive voice. It SHALL NOT contain definitions or links, not even to other REQs; terms are defined in the glossary. -->
The Library SHALL read a data file only if its Format Version is one the Library supports. The Library SHALL skip any other data file and SHALL report it to the Trace.

## Justification
<!-- A sound reasoning why this requirement exists and not another one. Any revision of the REQ MUST take the justification into serious consideration. -->
Reading a file in a format the Library does not understand would silently produce wrong Details. The Format Version makes it possible to support older formats later, while files without one are excluded on purpose.
