# Missing Relations File
## Context
<!-- The situation that makes this requirement necessary, e.g. a user need, a law or standard, or a constraint from another system. -->
A data collector may enter Persons before any Relation, so a Data Folder can lack its Relations File. No other requirement says what the Library does then; the question came up while writing the unit tests.

## Requirement Statement
<!-- A bland statement of the requirement using the [RFC 2119](https://datatracker.ietf.org/doc/html/rfc2119) standardized vocabulary. The ruling SHALL be stated in an assertive voice. It SHALL NOT contain definitions or links, not even to other REQs; terms are defined in the glossary. -->
If a Data Folder contains no Relations File named "relations.csv", the Library SHALL create the Context without Relations, and SHALL report the missing Relations File to the Trace.

## Justification
<!-- A sound reasoning why this requirement exists and not another one. Any revision of the REQ MUST take the justification into serious consideration. -->
The Persons are worth looking at without their Relations, and a missing file is a problem in the data like a malformed one: the Library works around it and says so, instead of showing nothing.
