# Columns of the Relations File
## Context
<!-- The situation that makes this requirement necessary, e.g. a user need, a law or standard, or a constraint from another system. -->
Every row of the existing Relations File holds the Person Id of the first Person, the Person Id of the second Person, the Relation Type, the Relationship, the start date and the end date, in this order. Often only the first three are known.

## Requirement Statement
<!-- A bland statement of the requirement using the [RFC 2119](https://datatracker.ietf.org/doc/html/rfc2119) standardized vocabulary. The ruling SHALL be stated in an assertive voice. It SHALL NOT contain definitions or links, not even to other REQs; terms are defined in the glossary. -->
Every row of the Relations File after the first SHALL contain the Person Id of the first Person, the Person Id of the second Person and the Relation Type, in this order. A row MAY additionally contain the Relationship, the start date and the end date, in this order.

## Justification
<!-- A sound reasoning why this requirement exists and not another one. Any revision of the REQ MUST take the justification into serious consideration. -->
The Relation Type is all the Library needs to place Persons into Generations; the other columns only describe the Relation to the reader.
