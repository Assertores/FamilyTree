# Exploring the Family Tree
<!-- State: Proposed (not part of a work package yet), Planned (part of a work package), In Progress (one of its work packages is being implemented), Implemented (all its work packages are Done), Done (every scenario has a passing end-to-end test), Rejected (dropped without a successor; a replaced FTR keeps its state and gets `Replaced by` instead). -->
## User Story
<!-- Who wants what, and why. Use the form: As a <user group>, I want <goal>, so that <benefit>. The user group should match one from the vision's Target Users. -->
As a family member, I want to see a Person together with their family, as far as I choose, so that I understand how the people of my family are related.

## Requirements
<!-- The REQs that constrain how this feature may be built, and how each one affects it. -->
| Requirement | Constraint |
| ---: | :--- |
| [REQ 0029](../requirements/req_0029.md) | The Family Tree shows the selected Person and every Family within the chosen Distance with all its members, ordered by Generation. |
| [REQ 0022](../requirements/req_0022.md) | The Library provides the Families and Generations, so that the Browsing Application only draws them. |
| [REQ 0045](../requirements/req_0045.md) | Children are drawn below their Parents, and all Parents of a Child in the same Generation. |
| [REQ 0046](../requirements/req_0046.md) | Every label is in German. |

## Scenarios
<!-- Concrete examples of the feature's behavior: the normal case first, then edge cases and errors. Every step must be observable from the outside. -->
### The closest family
- **Given** A and B are the Parents of C and D, and E and F are the Parents of A
- **When** the user shows the Family Tree of A with the Distance 0
- **Then** E and F are shown in the top row, A and B in the row below, and C and D in the row below that

### One step further
- **Given** A and B are the Parents of C, and C and G are the Parents of H
- **When** the user shows the Family Tree of A with the Distance 1
- **Then** A, B, C, G and H are shown, with G in the same row as C

### Families stay whole
- **Given** A and B are the Parents of C
- **When** the user shows the Family Tree of C with the Distance 0
- **Then** both A and B are shown above C

### A Person without a family
- **Given** a Person who is in no Relation
- **When** the user shows the Family Tree of this Person
- **Then** only this Person is shown
