# Listening to the Stories in the Family Tree
<!-- State: Proposed (not part of a work package yet), Planned (part of a work package), In Progress (one of its work packages is being implemented), Implemented (all its work packages are Done), Done (every scenario has a passing end-to-end test), Rejected (dropped without a successor; a replaced FTR keeps its state and gets `Replaced by` instead). -->
## User Story
<!-- Who wants what, and why. Use the form: As a <user group>, I want <goal>, so that <benefit>. The user group should match one from the vision's Target Users. -->
As a family member, I want to listen to the recorded stories of my ancestors while I move through the Family Tree, so that it feels like walking through the tree by listening to their stories.

## Requirements
<!-- The REQs that constrain how this feature may be built, and how each one affects it. -->
| Requirement | Constraint |
| ---: | :--- |
| [REQ 0012](../requirements/req_0012.md) | The Recording plays inside the Browsing Application, started from the Person in the Family Tree, and can be paused and continued. |
| [REQ 0024](../requirements/req_0024.md) | The Library plays the Recording through the Platform; the Browsing Application replaces that part of the Platform with its own player. |
| [REQ 0037](../requirements/req_0037.md) | The Browsing Application can replace the part of the Platform that plays Recordings. |
| [REQ 0011](../requirements/req_0011.md) | The Recording is found relative to the Person Folder. |
| [REQ 0025](../requirements/req_0025.md) | A missing Recording does not crash the Browsing Application. |
| [REQ 0046](../requirements/req_0046.md) | Everything the story player shows is in German. |

## Scenarios
<!-- Concrete examples of the feature's behavior: the normal case first, then edge cases and errors. Every step must be observable from the outside. -->
### Listening to a story
- **Given** a Person whose Person File references a Recording that lies in their Person Folder
- **When** the user starts the Recording from the Person in the Family Tree
- **Then** the Recording plays inside the Browsing Application

### Pausing and continuing
- **Given** a Recording that is playing
- **When** the user pauses it and later continues it
- **Then** the Recording stops, and then continues from where it stopped

### A Person without a story
- **Given** a Person whose Person File references no Recording
- **When** the user looks at this Person in the Family Tree
- **Then** no Recording is offered for this Person
