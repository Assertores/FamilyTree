# Opening a Data Folder
<!-- State: Proposed (not part of a work package yet), Planned (part of a work package), In Progress (one of its work packages is being implemented), Implemented (all its work packages are Done), Done (every scenario has a passing end-to-end test), Rejected (dropped without a successor; a replaced FTR keeps its state and gets `Replaced by` instead). -->
## User Story
<!-- Who wants what, and why. Use the form: As a <user group>, I want <goal>, so that <benefit>. The user group should match one from the vision's Target Users. -->
As a family member, I want to choose the Data Folder that holds my family's data and open it in the Browsing Application, so that I can explore my family wherever I keep the data.

## Requirements
<!-- The REQs that constrain how this feature may be built, and how each one affects it. -->
| Requirement | Constraint |
| ---: | :--- |
| [REQ 0026](../requirements/req_0026.md) | The user chooses the Data Folder; it is not in a fixed place next to the program. |
| [REQ 0001](../requirements/req_0001.md) | Only Person Files whose Format Version the Library supports are read; all others are skipped. |
| [REQ 0006](../requirements/req_0006.md) | The Relations File is only read if the Library supports its Format Version. |
| [REQ 0045](../requirements/req_0045.md) | Every Person gets a Generation while the Data Folder is opened. |
| [REQ 0047](../requirements/req_0047.md) | A Data Folder with conflicting Generations is not opened. |
| [REQ 0040](../requirements/req_0040.md) | A Data Folder on a network drive can be opened, but the Browsing Application opens no network connection itself. |
| [REQ 0046](../requirements/req_0046.md) | Everything the Browsing Application says while opening is in German. |
| [REQ 0027](../requirements/req_0027.md) | The Persons of the opened Data Folder are found with the search of the Browsing Application. |

## Scenarios
<!-- Concrete examples of the feature's behavior: the normal case first, then edge cases and errors. Every step must be observable from the outside. -->
### Opening a Data Folder
- **Given** a Data Folder with three Person Folders and a Relations File, all with a supported Format Version
- **When** the user chooses this Data Folder
- **Then** each of the three Persons can be found with a search

### A Person File with an unsupported Format Version
- **Given** a Data Folder with three Person Folders, one of which holds a Person File with a Format Version the Library does not support
- **When** the user chooses this Data Folder
- **Then** the two other Persons can be found with a search, and the third cannot
