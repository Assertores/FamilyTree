# Seeing the Details of a Person

## User Story
<!-- Who wants what, and why. Use the form: As a <user group>, I want <goal>, so that <benefit>. The user group should match one from the vision's Target Users. -->
As a family member, I want to see everything that is recorded about a Person, so that I learn who they were.

## Requirements
<!-- The REQs that constrain how this feature may be built, and how each one affects it. -->
| Requirement | Constraint |
| ---: | :--- |
| [REQ 0028](../requirements/req_0028.md) | Every Detail is shown, and unknown Details are shown as unknown. |
| [REQ 0014](../requirements/req_0014.md) | All Details of the Person are available to the Browsing Application. |
| [REQ 0015](../requirements/req_0015.md) | The Browsing Application can tell which Details are missing in the Person File. |
| [REQ 0009](../requirements/req_0009.md) | Details are shown exactly as they are written, without interpreting dates or places. |
| [REQ 0046](../requirements/req_0046.md) | Every label is in German. |

## Scenarios
<!-- Concrete examples of the feature's behavior: the normal case first, then edge cases and errors. Every step must be observable from the outside. -->
### Seeing every Detail
- **Given** a Person File with a title, two first names, a title of nobility, a last name, a gender, a date and place of birth, a date and place of death, two professions, two Places of Residence with their dates, and a remark
- **When** the user selects the Person
- **Then** every one of these Details is shown

### Dates are shown as written
- **Given** a Person whose date of birth is written as "um 1850"
- **When** the user selects the Person
- **Then** the date of birth is shown as "um 1850"

### Unknown Details
- **Given** a Person File without a date of death
- **When** the user selects the Person
- **Then** the date of death is shown as unknown
