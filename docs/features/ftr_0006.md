# Looking at the Pictures of a Person
<!-- State: Proposed (not part of a work package yet), Planned (part of a work package), In Progress (one of its work packages is being implemented), Implemented (all its work packages are Done), Done (every scenario has a passing end-to-end test), Rejected (dropped without a successor; a replaced FTR keeps its state and gets `Replaced by` instead). -->
## User Story
<!-- Who wants what, and why. Use the form: As a <user group>, I want <goal>, so that <benefit>. The user group should match one from the vision's Target Users. -->
As a family member, I want to look at the Pictures of a Person, so that I see the faces and places of my ancestors.

## Requirements
<!-- The REQs that constrain how this feature may be built, and how each one affects it. -->
| Requirement | Constraint |
| ---: | :--- |
| [REQ 0030](../requirements/req_0030.md) | The user can show the Pictures of a selected Person. |
| [REQ 0048](../requirements/req_0048.md) | The Pictures are shown inside the Browsing Application, one at a time, and the user switches to the next and the previous one. |
| [REQ 0023](../requirements/req_0023.md) | The Library shows the Pictures through the Platform; the Browsing Application replaces that part of the Platform with its carousel. |
| [REQ 0037](../requirements/req_0037.md) | The Browsing Application can replace the part of the Platform that shows Pictures. |
| [REQ 0011](../requirements/req_0011.md) | The Pictures are found relative to the Person Folder, also after the Data Folder was moved. |
| [REQ 0025](../requirements/req_0025.md) | A Person without Pictures, or a missing Picture file, does not crash the Browsing Application. |
| [REQ 0046](../requirements/req_0046.md) | Everything the carousel shows is in German. |
| [REQ 0026](../requirements/req_0026.md) | The user opens the Data Folder wherever it was copied to. |

## Scenarios
<!-- Concrete examples of the feature's behavior: the normal case first, then edge cases and errors. Every step must be observable from the outside. -->
### Looking at the Pictures
- **Given** a Person whose Person File references two Pictures that lie in their Person Folder
- **When** the user chooses to show the Pictures of the Person
- **Then** the first Picture is shown inside the Browsing Application

### Switching between the Pictures
- **Given** the first of the two Pictures of a Person is shown
- **When** the user switches to the next Picture, and then to the previous one
- **Then** the second Picture is shown, and then the first one again

### After moving the Data Folder
- **Given** the Data Folder of the previous scenario was copied to another computer
- **When** the user opens it there and chooses to show the Pictures of the Person
- **Then** the first Picture is shown, and the user can switch to the second

### A Person without Pictures
- **Given** a Person whose Person File references no Pictures
- **When** the user chooses to show the Pictures of the Person
- **Then** no Picture is shown, and the Browsing Application keeps working
