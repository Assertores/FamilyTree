# Searching for a Person
<!-- State: Proposed (not part of a work package yet), Planned (part of a work package), In Progress (one of its work packages is being implemented), Implemented (all its work packages are Done), Done (every scenario has a passing end-to-end test), Rejected (dropped without a successor; a replaced FTR keeps its state and gets `Replaced by` instead). -->
## User Story
<!-- Who wants what, and why. Use the form: As a <user group>, I want <goal>, so that <benefit>. The user group should match one from the vision's Target Users. -->
As a family member, I want to find a Person by what I remember about them, e.g. part of a name or a place, so that I can start exploring the family from someone I know.

## Requirements
<!-- The REQs that constrain how this feature may be built, and how each one affects it. -->
| Requirement | Constraint |
| ---: | :--- |
| [REQ 0027](../requirements/req_0027.md) | The Browsing Application offers a search by Details and lists the Persons found. |
| [REQ 0016](../requirements/req_0016.md) | A search text matches if it is contained in the Detail, or in any one value of a Detail with several values; empty search fields are ignored; missing Details never match. |
| [REQ 0046](../requirements/req_0046.md) | The search is in German. |

## Scenarios
<!-- Concrete examples of the feature's behavior: the normal case first, then edge cases and errors. Every step must be observable from the outside. -->
### Searching for a second first name
- **Given** a Person with the first names "Philippa" and "Rosa"
- **When** the user searches for the first name "Rosa"
- **Then** the Person is listed

### Searching for part of a name
- **Given** a Person with the last name "Perry"
- **When** the user searches for the last name "Per"
- **Then** the Person is listed

### Empty search fields are ignored
- **Given** a Person with the first name "Anna"
- **When** the user searches for the first name "Anna" and leaves every other field empty
- **Then** the Person is listed

### A missing Detail does not match
- **Given** a Person whose Person File has no place of birth
- **When** the user searches for the place of birth "a"
- **Then** the Person is not listed
