# clang
## Choice
<!-- Exactly what was chosen. -->
| Name | Version | Source | License |
| ---: | :--- | :--- | :--- |
| clang | 23.1 | https://clang.llvm.org | Apache-2.0 WITH LLVM-exception |

## Description
<!-- What the dependency is, what it does, and what this project uses it for. -->
The C and C++ compiler of the LLVM project. The project compiles the Library, the Applications and the tests with it, on Windows and on Linux, and uses its AddressSanitizer and LeakSanitizer while the tests run.

## Alternatives Considered
<!-- What else was evaluated, and what speaks for and against each option. -->
| Name | Pros | Cons |
| ---: | :--- | :--- |
| GCC | the standard compiler on Linux, good C99 support | not native on Windows; a second toolchain next to clang-format and clang-tidy |
| MSVC | the standard compiler on Windows | Windows only; its C99 support came late and is incomplete; different warning flags |

## Justification
<!-- A sound reasoning why this dependency was chosen over the alternatives, and over building it ourselves. Any replacement of the dependency MUST take the justification into serious consideration. -->
clang runs on Windows and Linux with the same flags and warnings, belongs to the same LLVM toolchain as clang-format and clang-tidy, and brings the sanitizers that find the memory leaks the original implementation suffered from. The Library itself must still build with any C99 compiler, so clang is the compiler of the project, not a requirement of the Library.
