# clang-format
## Choice
<!-- Exactly what was chosen. -->
| Name | Version | Source | License |
| ---: | :--- | :--- | :--- |
| clang-format | 23.1 | https://clang.llvm.org/docs/ClangFormat.html | Apache-2.0 WITH LLVM-exception |

## Description
<!-- What the dependency is, what it does, and what this project uses it for. -->
Formats C and C++ code according to a configuration file. The project uses the configuration of the original implementation, `.clang-format`, for the Library and the Applications.

## Alternatives Considered
<!-- What else was evaluated, and what speaks for and against each option. -->
| Name | Pros | Cons |
| ---: | :--- | :--- |
| Manual formatting | no tool | inconsistent and time consuming |
| Uncrustify | very configurable, supports C well | less common, a second configuration for the Applications |

## Justification
<!-- A sound reasoning why this dependency was chosen over the alternatives, and over building it ourselves. Any replacement of the dependency MUST take the justification into serious consideration. -->
clang-format formats C and C++ with one configuration, is part of every LLVM installation and is supported by most editors.
