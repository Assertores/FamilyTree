# GitHub Actions
## Choice
<!-- Exactly what was chosen. -->
| Name | Version | Source | License |
| ---: | :--- | :--- | :--- |
| GitHub Actions | hosted service, runners `ubuntu-latest` and `windows-latest` | https://github.com/features/actions | proprietary service, free for public repositories and with a monthly allowance for private ones |

## Description
<!-- What the dependency is, what it does, and what this project uses it for. -->
A continuous integration service of GitHub. The project builds and tests on Linux and Windows with it, and gets the Windows version of the Applications, bundled with Qt, as a downloadable artifact.

## Alternatives Considered
<!-- What else was evaluated, and what speaks for and against each option. -->
| Name | Pros | Cons |
| ---: | :--- | :--- |
| Building on Windows by hand | no service needed | the author works on Linux; easy to forget a step when bundling Qt |
| Cross-compiling on Linux | everything on one machine | fiddly to set up, especially Qt Multimedia for Windows |
| GitLab CI | similar, can be self-hosted | the repository lives on GitHub |

## Justification
<!-- A sound reasoning why this dependency was chosen over the alternatives, and over building it ourselves. Any replacement of the dependency MUST take the justification into serious consideration. -->
The repository is on GitHub, the original implementation already used GitHub Actions, and Windows runners are available without own hardware. Only building and testing depend on it; the Library and the data do not.
