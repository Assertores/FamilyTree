# clang-tidy
## Choice
<!-- Exactly what was chosen. -->
| Name | Version | Source | License |
| ---: | :--- | :--- | :--- |
| clang-tidy | 23.1 | https://clang.llvm.org/extra/clang-tidy/ | Apache-2.0 WITH LLVM-exception |

## Description
<!-- What the dependency is, what it does, and what this project uses it for. -->
A static analyzer and linter for C and C++. The Library has its own configuration with checks for C, which enforce parts of the Power of Ten rules, e.g. no recursion, short functions and checked return values. The Applications keep the C++ configuration of the original implementation.

## Alternatives Considered
<!-- What else was evaluated, and what speaks for and against each option. -->
| Name | Pros | Cons |
| ---: | :--- | :--- |
| cppcheck | made for C, has an addon for MISRA C | the MISRA rules themselves are not freely available; a second tool next to clang-tidy for the Applications |
| Compiler warnings only | no extra tool | do not cover the Power of Ten rules |

## Justification
<!-- A sound reasoning why this dependency was chosen over the alternatives, and over building it ourselves. Any replacement of the dependency MUST take the justification into serious consideration. -->
clang-tidy analyzes the Library and the Applications with one tool, and several of its checks enforce Power of Ten rules directly. The original implementation already uses it; it only lacked a configuration for C.
