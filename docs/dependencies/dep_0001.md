# Qt
## Choice
<!-- Exactly what was chosen. -->
| Name | Version | Source | License |
| ---: | :--- | :--- | :--- |
| Qt | 6.12 | https://www.qt.io | LGPL-3.0 |

## Description
<!-- What the dependency is, what it does, and what this project uses it for. -->
A cross-platform framework for applications with a graphical user interface. The Browsing Application and the Data Entry Tool use its widgets, its graphics scene for the Family Tree, its media player for Recordings, its image loading for the picture carousel, its native file dialogs and its translation files. The Library does not use it.

## Alternatives Considered
<!-- What else was evaluated, and what speaks for and against each option. -->
| Name | Pros | Cons |
| ---: | :--- | :--- |
| Dear ImGui | small, already used by the original Applications, the author knows it | immediate mode: every position, text size, zoom and click of the Family Tree is left to the Application, which made the tree very hard to build; no audio, no images, no translations |
| Python with PySide6 | fastest way to write a user interface | Python environments age fast, and handing a working program to a user who is not a programmer is hard |
| Web application with the Library as WebAssembly | layout of boxes with HTML and SVG is easy | browsers restrict access to local folders; the Library would need a second toolchain |
| GTK | mature, free | its C++ binding is less common, and it is less at home on Windows |

## Justification
<!-- A sound reasoning why this dependency was chosen over the alternatives, and over building it ourselves. Any replacement of the dependency MUST take the justification into serious consideration. -->
Qt covers every need of the Applications in one dependency, and keeps the author in C++. Its retained mode graphics scene solves the problem that made the Family Tree hard with Dear ImGui. Building these parts ourselves is far beyond the scope of a bonus on top of the Library. Linking it dynamically satisfies its license.
