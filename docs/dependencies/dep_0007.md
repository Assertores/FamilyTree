# Doxygen
## Choice
<!-- Exactly what was chosen. -->
| Name | Version | Source | License |
| ---: | :--- | :--- | :--- |
| Doxygen | 1.18 | https://www.doxygen.nl | GPL-2.0 |

## Description
<!-- What the dependency is, what it does, and what this project uses it for. -->
Generates HTML documentation from comments in source code. The project runs it over the public header of the Library with the CMake target `documentation`, and treats every warning as an error, so that an undocumented function or parameter fails the target.

## Alternatives Considered
<!-- What else was evaluated, and what speaks for and against each option. -->
| Name | Pros | Cons |
| ---: | :--- | :--- |
| Reading the header only | no tool | no overview, no check that everything is documented |
| Sphinx with Breathe | nicer pages | needs Python and Doxygen anyway |

## Justification
<!-- A sound reasoning why this dependency was chosen over the alternatives, and over building it ourselves. Any replacement of the dependency MUST take the justification into serious consideration. -->
The header is documented in Doxygen format ([docs/conventions.md](../conventions.md)), as in the original implementation, which already used Doxygen. CMake supports it directly. The GPL covers only the tool; the generated documentation and the code are not affected. The header stays readable without it, so the documentation does not depend on Doxygen surviving.
