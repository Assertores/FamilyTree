# CMake
## Choice
<!-- Exactly what was chosen. -->
| Name | Version | Source | License |
| ---: | :--- | :--- | :--- |
| CMake | 4.5 (at least 3.20) | https://cmake.org | BSD-3-Clause |

## Description
<!-- What the dependency is, what it does, and what this project uses it for. -->
A build system generator. It builds the Library, the Applications and the tests on Windows and Linux, and runs clang-tidy during the build.

## Alternatives Considered
<!-- What else was evaluated, and what speaks for and against each option. -->
| Name | Pros | Cons |
| ---: | :--- | :--- |
| Make | available everywhere on Linux | not native on Windows; Makefiles for both systems would differ |
| Meson | simple, fast | needs Python; less common for Qt projects |
| No build system | nothing to install | the Applications and tests with Qt are hard to build by hand |

## Justification
<!-- A sound reasoning why this dependency was chosen over the alternatives, and over building it ourselves. Any replacement of the dependency MUST take the justification into serious consideration. -->
CMake is the most common build system for C and C++, Qt supports it directly, and the original implementation already uses it. It stays a convenience: the Library builds without it, with a single compiler call.
